#  Secure User Authentication System - Full stack web application 
A full-stack web application that provides a secure and seamless authentication experience for modern web and mobile platforms. Built with **ReactJS**, **Node.js**, **ExpressJS**, **MongoDB**, and **TailwindCSS**, the system supports user registration, email verification, login, password reset, and account management.

## Live Demo :https://new-auth-project.onrender.com/login

## Features
 ✅ **User Registration** with email and password
- 📧 **Email Verification** via tokenized link with expiration
- 🔐 **Secure Login** with session handling or JWT tokens
- 🔁 **Password Reset** via secure token link
- 👤 **User Dashboard** with:
  - Profile update
  - Login activity tracking
  - Password change
- 🔒 **Token Expiry and Validation** for all critical flows
- 🎨 **Responsive UI** using TailwindCSS
